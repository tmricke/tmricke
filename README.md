## 🚀 Featured Homelab

### Windows Server and Network Lab

Built a virtualized environment using Windows Server 2022, Windows 10/11 clients, Ubuntu Server, and pfSense. The lab supports hands-on practice with:

- Active Directory, DNS, and DHCP configuration
- User, group, permission, and domain-join administration
- Virtual network design, NAT, and firewall rules
- Windows-to-Linux connectivity and service testing
- Structured troubleshooting using symptoms, hypotheses, tests, results, and fixes

I am rebuilding and documenting the environment so each exercise shows not only the final configuration, but also how I approached the problem and validated the solution.
